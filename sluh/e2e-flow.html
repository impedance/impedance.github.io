02

Состояния деградации и альтернативные состояния

Сбой не маскируется под «успех», а основной путь остаётся читаемым.

Duplicate / invalid Observation — дубликат или неверное наблюдение

Дедупликация или явное отклонение; второй бизнес-факт не создаётся.

Тайм-аут алгоритма / недостаточно данных

Явное состояние; фиктивный успех не создаётся.

Missing audio — аудио недоступно

Недоступность указывается явно; блокирует ли она решение — OPEN.

Target without position — цель без положения

PotentialTarget может существовать и отображаться без позиции.

Повторное подключение (Reconnect)

Свежий снимок → обновления в реальном времени; долговечное воспроизведение для MVP не обязательно.

Access isolation — изоляция доступа

Пользователь объекта A не получает объект B через чтение, аудио, обновления в реальном времени или команду.

Multi-target

Цели раздельны и различимы; точный N-target SLA — OPEN.

Ground Truth mismatch — расхождение с Ground Truth

Без корректной синхронизации времени свидетельства полевого прогона недостоверны.

03

Сквозная проверка

Главная проверяемая способность — объяснить, почему цель появилась и какое решение было принято.

Прослеживаемость: Observation → результаты алгоритмов → PotentialTarget/Track → операторская проекция → OperatorDecision → свидетельства FieldTrial. Время события ≠ времени приёма; версия алгоритма сохраняется; Ground Truth независим.
